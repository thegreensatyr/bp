Scheduling Tumblr Posts Across Multiple Blogs

Tumblr makes it easy to run several blogs under one login — which also makes it easy to schedule a post to the wrong one. Here's how to keep that from happening.

BrandParent · Updated November 2026

Tumblr connects with a simple sign-in — no developer review, no app password step. That's convenient, but it also means the scheduler you use needs to be explicit about which blog a post is going to, because Tumblr itself will quietly default to your primary blog if a tool doesn't ask.

Step 1: Sign in once, pick the blog every time

When you connect Tumblr to a scheduler, confirm it's asking which blog to post to — not assuming. In BrandParent, the Tumblr connection lives inside a specific cubicle, and posts from that cubicle go to the blog tied to that brand. If you run three Tumblr blogs for three different projects, each one gets its own cubicle and its own connection, so there's no blog-picker step to get wrong at publish time.

Step 2: Separate the voice, not just the account

The account-switching problem is the obvious one. The quieter problem is voice: if you're writing posts for two blogs back to back, it's easy for phrasing, tags, or inside references from one blog to drift into the other — especially late at night, which is when a lot of Tumblr posting happens. A voice profile per brand (tone, lexicon, phrases you'd never use) catches this before publish, not after a follower points it out.

Step 3: Schedule ahead, review per-queue

Each brand's upcoming posts should be reviewable on their own — not mixed into one combined calendar where it's easy to approve the wrong thing because you're scanning fast. BrandParent keeps each cubicle's "Up next" queue fully separate, so reviewing Tuesday's lineup for one blog never shows you drafts for another.

If you only run one Tumblr blog, none of this matters — post however you like. This is specifically for the moment you're running two or more and the context-switching starts costing you mistakes.
